# TOMONI AI HTMLプレゼンテーション

`index.html` をブラウザーで開くと、外部通信なしで閲覧できます。
表示用HTMLにはフォント・画像・本文・補足・出典を埋め込んでいます。

## 操作

- ↓ / PageDown / Space：次のページ
- ↑ / PageUp：前のページ
- Home / End：最初 / 最後
- 右下の矢印：次へ / 戻る
- INDEX または M：目次
- 詳細資料 または D：詳細資料の本文・表・補足・出典
- F：全画面（対応ブラウザーのみ）
- Esc：開いている目次・詳細資料を閉じる

スマートフォンは通常のスクロールでも読めます。
OSで「視差効果を減らす」などが有効な場合は、モーションを抑えます。

## 編集用ソース

- `index.template.html`：ページの枠組み
- `styles.css`：デザインとモーション
- `app.js`：24場面の本文・ページ移動・詳細資料
- `art.js`：オリジナルSVGキャラクターとイラスト
- `source-slides.json`：詳細資料46項目の本文・表・補足・出典
- `licenses/`：同梱フォントのライセンスと出典

最終HTMLを変更する場合、編集したソースを再び埋め込む必要があります。
この作業用ワークスペースでは `.pitch-build/html-deck/build.py` が生成スクリプトです。
